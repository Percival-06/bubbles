# Bubbles Remotion Background

This folder contains the Remotion source for the B option: a cinematic deep-sea cover and main menu background.

Install and render when npm is available:

```bash
npm install
npm run cover
npm run menu
```

The game consumes:

- `../assets/backgrounds/cover_deep_sea.png`
- `../assets/backgrounds/main_menu_deep_sea.png`
