# Bubbles

《Bubbles》是一款基于 Python + Pygame 的单人冒险解谜游戏。玩家控制一颗携带生命种子的泡泡，从深海向上抵达终点，在移动过程中管理体积、密度、能量和污染风险。

## 运行方式

```bash
python main.py
```

## 操作说明

- `A/D` 或方向键左右移动。
- `X` 释放小泡泡，减少体积并提高密度，使泡泡更容易下沉。
- 接触小泡泡会吸收体积，使泡泡更容易上浮。
- 接触能量种子会恢复生命能量。
- `Esc` 打开暂停菜单。

## 核心玩法

- 泡泡的垂直运动由质量、体积和密度共同决定，没有传统跳跃。
- 能量会随时间消耗，污染区域会额外增加污染值并加快能量损失。
- 每关目标是抵达终点，同时尽量收集能量种子以获得更高星级评价。
- 通关后自动解锁下一关，关卡目录可重复挑战已解锁关卡。

## 关卡递进

- 教学关：熟悉体积调节、上浮下沉和基础收集。
- 深海通道：引入污染区域，强调路线选择。
- 中层海域：空间更窄、污染更密集，要求综合管理体积、能量与风险。

## 设计实现对应

- 主流程：主菜单、关卡目录、游戏、暂停、设置、结算界面形成完整闭环。
- 存档：自动保存已解锁关卡、已完成关卡、最高星级和设置开关。
- HUD：展示生命能量、污染、密度、能量种子收集进度和星级反馈。
- 关卡目录：选中关卡时显示玻璃风格详情卡、关卡说明、星级和缩略地图。
